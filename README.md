# PyWebWinUI3 소개 페이지

Python으로 Windows 데스크톱 UI를 만드는 프레임워크 PyWebWinUI3를 소개하는 반응형 웹페이지입니다.

## JavaScript 이벤트

- `click`: 빠른 안내의 설치, 화면 구성, 상태 연결 탭을 누르면 선택된 탭의 내용만 표시됩니다.
- `input`: 문의 내용을 입력하면 글자 수와 전송 가능 여부가 실시간으로 바뀝니다.
- `change`: 문의 유형을 바꾸면 해당 유형에 맞는 작성 안내와 강조 스타일이 표시됩니다.
- `submit`: 이름, 이메일, 문의 유형, 문의 내용을 확인한 뒤 결과 문구와 스타일, 버튼 문구와 사용 가능 상태가 함께 바뀝니다.

## 화면 변화

- 선택된 탭은 흰색 배경과 진한 글자로 구분되며, 선택하지 않은 탭의 내용은 숨겨집니다.
- 문의 내용이 10자 이상이면 글자 수 안내가 초록색으로 바뀝니다.
- 문의 유형을 선택하면 작성 안내 문구가 바뀌고 파란색으로 강조됩니다.
- 입력값이 올바르면 전송 완료 문구가 표시되고 버튼이 비활성화됩니다. 입력이 부족하면 오류 안내와 다시 확인할 버튼이 표시됩니다.
