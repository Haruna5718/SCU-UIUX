# PyWebWinUI3 소개 페이지

Python 코드와 XAML 형식의 마크업으로 Windows 데스크톱 UI를 만드는 PyWebWinUI3를 소개하는 반응형 웹페이지입니다. 주요 기능과 기본 예제, 실제 제작 사례를 살펴보고 프로젝트 시작 구성을 직접 만들어 볼 수 있습니다.

## 사용자와 서비스 목적

- 주요 사용자: Python으로 Windows 데스크톱 앱을 만들려는 개발자
- 서비스 목적: PyWebWinUI3의 특징과 활용 방법을 이해하고, 만들려는 프로젝트에 맞는 시작 구성을 정할 수 있도록 안내
- 핵심 행동: 프로젝트 이름과 목적, 우선 기능을 선택하고 추천 시작 구성을 확인
- 완료 조건: 사용자가 입력하고 선택한 내용이 확인 화면에 반영되고, 적합한 첫 화면과 구성 요소가 제시됨

## 사용자 흐름

프로젝트 시작 도우미는 네 단계로 구성했습니다.

1. 시작: 도우미의 목적을 확인하고 `시작 구성 만들기`를 선택합니다.
2. 입력: 프로젝트 이름, 프로젝트 목적, 가장 필요한 기능을 입력하거나 선택합니다.
3. 확인: 입력한 내용을 검토합니다. `이전 단계`를 선택하면 값을 유지한 채 수정할 수 있습니다.
4. 완료: `추천 구성 만들기`를 선택해 첫 화면 파일과 추천 구성 요소를 확인합니다. `다시 시작`을 선택하면 도우미의 상태가 초기화됩니다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 시작 구성 만들기 선택 | `click` | 시작 화면 | 입력 화면을 열고 2단계를 강조 | 입력 |
| 프로젝트 정보 작성·선택 | `input`, `change` | 각 항목의 입력 또는 선택 여부 | 이전 오류 문구를 지우고 입력 상태 유지 | 입력 |
| 구성 확인 선택 | `click` | 필수값이 하나 이상 누락됨 | 누락 안내를 표시하고 첫 번째 누락 항목으로 이동 | 입력 |
| 구성 확인 선택 | `click` | 모든 필수값이 입력됨 | 입력값을 요약하고 3단계를 강조 | 확인 |
| 이전 단계 선택 후 수정 | `click`, `input`, `change` | 확인 화면 | 기존 값을 유지하고, 다시 확인하면 수정값을 요약에 반영 | 입력 → 확인 |
| 추천 구성 만들기 선택 | `submit` | 확인 화면 | 선택한 목적과 기능에 맞는 첫 화면과 구성 요소를 표시 | 완료 |
| 다시 시작 선택 | `click` | 완료 화면 | 입력·선택·오류·요약·추천 결과·진행 단계를 모두 초기화 | 시작 |

## 기존 기능

- 설치, 화면 구성, 상태 연결 정보를 전환하는 탭 3개
- 이름, 이메일, 문의 유형, 문의 내용을 받는 문의 폼
- 입력과 선택에 따라 달라지는 문의 안내 문구와 버튼 상태
- 반응형 내비게이션, 기능 카드, 이미지, 예제 코드 영역

문의 폼과 프로젝트 시작 도우미는 프런트엔드 동작을 확인하기 위한 예제이며 입력한 정보는 실제 서버로 전송되지 않습니다.
