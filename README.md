# PyWebWinUI3 소개 페이지

Python과 XAML 형식의 마크업으로 Windows 데스크톱 UI를 만드는 PyWebWinUI3를 소개하고, 프로젝트 시작 구성을 정할 수 있는 반응형 웹페이지입니다.

## 서비스와 사용자

- 주요 사용자: Python으로 Windows 데스크톱 앱을 만들려는 개발자
- 서비스 목적: PyWebWinUI3의 특징과 활용 방법을 이해하고 프로젝트 시작 구성을 정하도록 안내
- 핵심 행동: 프로젝트 정보를 입력해 추천 구성을 만들고 구현 준비 항목을 확인
- 완료 조건: 입력한 정보가 추천 결과에 반영되고 구현 준비 항목 3개를 모두 확인함

## 주차별 추가 사항

- 1주차: 제목과 소개 문장으로 구성한 기본 HTML 페이지 제작
- 2주차: PyWebWinUI3 소개, 기능, 이용 방법, 이미지, 문의 입력 영역과 내부 이동 구조 추가
- 3주차: 글자, 색상, 여백, 테두리와 영역 구분을 적용한 CSS 화면 완성
- 4주차: viewport, 유동 너비, CSS Grid와 768px 반응형 배치 적용
- 5주차: 문의 폼 입력 검사와 전송 결과 안내 기능 추가
- 6주차: `click`·`input`·`change` 이벤트, 탭 3개와 동적 화면 피드백 추가
- 7주차: 시작 → 입력 → 확인 → 완료로 이어지는 프로젝트 시작 도우미 추가
- 중간고사: 7주차 추천 결과 뒤에 진행률이 바뀌는 구현 준비 체크리스트 추가

## JavaScript 이벤트와 화면 변화

- `click`: 탭과 단계 이동 버튼을 누르면 선택된 콘텐츠 또는 다음 단계가 표시됩니다.
- `input`: 문의 내용을 입력하면 글자 수와 전송 가능 안내가 바뀝니다.
- `change`: 문의 유형 안내와 체크리스트 진행률, 남은 항목 수가 바뀝니다.
- `submit`: 문의 값 또는 프로젝트 값을 검사하고 오류나 완료 결과를 표시합니다.
- 선택 탭, 안내 문구 스타일, 버튼 활성 상태가 사용자 행동에 따라 함께 변경됩니다.

## 사용자 흐름과 인터랙션

1. 프로젝트 이름, 목적, 필요한 기능을 입력합니다.
2. 입력 내용을 확인하고 필요하면 이전 단계에서 수정합니다.
3. 추천 페이지와 컴포넌트를 확인합니다.
4. 구현 준비 체크리스트를 열어 준비 항목을 확인합니다.
5. 모든 항목을 선택해 구현 준비를 완료합니다.

| 사용자 행동 | 확인 조건 | 화면 반응 | 다음 행동 |
| --- | --- | --- | --- |
| 구성 확인 선택 | 필수값 누락 | 수정 방법을 안내하고 입력 단계 유지 | 누락값 입력 |
| 구성 확인 선택 | 필수값 입력 완료 | 입력값을 반영한 확인 화면 표시 | 수정 또는 추천 생성 |
| 이전 단계 선택 | 확인 화면 | 입력값을 유지한 채 입력 화면 표시 | 수정 후 다시 확인 |
| 추천 구성 만들기 | 확인 완료 | 목적에 맞는 페이지와 컴포넌트 표시 | 구현 준비 확인 |
| 구현 준비 확인 | 추천 결과 존재 | 체크리스트와 0/3 진행률 표시 | 준비 항목 선택 |
| 준비 항목 일부 선택 | 3개 미만 선택 | 남은 항목 수 표시, 완료 버튼 비활성화 | 추가 선택 또는 결과로 돌아가기 |
| 추천 결과로 돌아가기 | 준비 확인 중 | 추천 결과로 이동하고 체크 상태 유지 | 체크리스트 다시 열기 |
| 준비 항목 모두 선택 | 3개 선택 | 3/3 안내와 완료 버튼 활성화 | 준비 완료 선택 |
| 준비 완료 선택 | 3개 선택 | 프로젝트 이름이 반영된 완료 화면 표시 | 새 구성 만들기 |
| 새 구성 만들기 | 완료 화면 | 입력값, 오류, 추천 결과와 체크 상태 초기화 | 새 프로젝트 입력 |
